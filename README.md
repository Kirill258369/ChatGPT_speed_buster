# ChatGPT Speed Booster 2.0

## Обновление
В Chrome / Edge откройте страницу управления расширениями, включите режим разработчика и нажмите «Обновить» у ChatGPT Speed Booster. Затем обновите открытые вкладки ChatGPT. Для первой установки используйте «Загрузить распакованное расширение» и выберите эту папку.

## Возможности
- Popup: переключатель ускорения, ползунок 2–100, быстрые значения, реальные счётчики и доля скрытых сообщений.
- Панель справа: поиск, навигация по результатам, закладки, навигатор, фильтр сообщений с кодом.
- «Ещё 10» раскрывает дополнительную порцию истории; «Показать историю» действует до обратного переключения или ухода из чата. «Вернуть лимит» отменяет временные раскрытия.
- Выбранное поиском сообщение временно раскрывается. Закрытие панели возвращает обычный лимит.
- Настройки каждого чата: собственный лимит и исключение из ускорения.
- Копирование всех блоков кода сообщения, в том числе с именами. Если DOM не содержит `data-filename`, используются нейтральные имена `block-N` с обозначением языка, а не предполагаемые имена исходных файлов.
- Сворачивание кода от 16 строк; раскрытие кнопкой под блоком.
- Фокус-режим скрывает боковую панель ChatGPT. Повторное нажатие возвращает её.
- Локальные шаблоны: создание, вставка в конец черновика без отправки, копирование и удаление.
- Экспорт доступных сообщений в Markdown либо безопасный HTML с текстом. Сложное оформление исходного ответа не сохраняется полностью.
- Автоускорение от заданного числа сообщений (0 — сразу). Общий переключатель должен быть включён.
- Alt+Shift+B — переключение ускорения; Alt+Shift+F — поиск; Alt+Shift+H — история. Буквы можно менять в настройках; повторы комбинаций запрещены. Используются физические клавиши, в том числе при русской раскладке. Системные сочетания могут иметь приоритет.

Поиск, навигатор, счётчики и экспорт работают только с сообщениями в DOM. Расширение не загружает отсутствующую историю через внутренние API. Закладка на отсутствующее сообщение сохраняется, но переход недоступен до его загрузки. Кнопка ↻ обновляет результаты поиска после появления новых сообщений.

## Архитектура
- `content.js`: исходные функции определения видимости, `hideBlock`, `showBlock`, восстановления и скрытия через `display: none`. Добавлены только правила из модулей и синхронизация. Сообщения не удаляются и не заменяются виртуальными элементами.
- `store.js`: прежний ключ настроек, совместимые значения по умолчанию.
- `tools.js`: отдельный модуль инструментов и временной политики раскрытия.
- `panel.js`: интерфейс в Shadow DOM; его изменения не вызывают повторную обработку чата.
- `popup.html`, `popup.js`, `main.css`: popup 2.0.

Старый баннер и его обработчики заменены новой панелью. Это устраняет повторное срабатывание наблюдателя от собственного UI и вызов отсутствующей функции в старой кнопке истории. Новых разрешений расширения и сетевой отправки данных нет. Текст закладок и шаблоны сохраняются локально в профиле браузера.

## Проверка версии
Автоматические проверки выполнены в установленном Chrome на тестовой странице с разметкой `section[data-turn-id]`: скрытие, исходные inline-стили, новые сообщения, история, поиск, изоляция закладок по чатам, лимиты, исключения, порог, горячие клавиши, код, шаблоны, экранирование HTML, popup и отсутствие бесконечного цикла наблюдателя. Chrome API в этих сценариях имитируются.

Полная загрузка распакованного расширения в отдельном тестовом Chromium не проверена: установленный тестовый бинарник не запустился. Проверка в вашей авторизованной сессии ChatGPT не выполнялась. После обновления проверьте длинный чат: интерфейс ChatGPT и его селекторы могут меняться.

### Ручная проверка
1. В чате длиннее лимита старые сообщения скрыты, последние видны; счётчик соответствует.
2. «Ещё 10», история, поиск по старому сообщению, закрытие панели и возврат лимита.
3. Закладка, переход в другой чат, возвращение и перезагрузка страницы.
4. Отправка нового запроса, потоковый ответ, переключение ветки ответа.
5. Собственный лимит, исключение чата и выключение общего переключателя.
6. Шаблон вставляется в черновик без отправки; экспорт читается вне ChatGPT.
